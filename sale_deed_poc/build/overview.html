Solution 4 · Sale Deed Chain Validator

From a stack of deeds to a verified ownership chain

A POC that reads property sale deeds (PDF or photo), reconstructs the chain of title, and flags every broken or missing link — with the evidence to back each call.

POC · ~5–6 days Python + Gemini flags, never auto-clears
The idea. Title due-diligence today means a person reading a pile of deeds line by line to check that ownership flows unbroken from one owner to the next. Solution 4 does that first pass in minutes and shows its working.
Design spine — the AI reads, the code judges: a vision model turns messy scans into structured data; deterministic code decides whether the chain holds. So the verdict is explainable, repeatable, and defensible — not a black box.

How it works — 4 stages

Each stage is a small, independently testable unit.

1
Ingestcode
Accept PDF or image; render pages, handle multi-page deeds, assign each a doc ID.
2
ExtractAI
A vision-LLM reads each deed into a strict JSON record — parties, property, extent, dates, consideration, e-stamp, and the prior-deed recital. Low-confidence fields are flagged, never silently trusted.
3
Chain-link & validatecode
Deterministic rules sort the deeds into a timeline and check each transfer: identity continuity, property & extent, recital linkage, dates → a verdict per link.
4
Reportoutput
A structured JSON ownership graph + a visual HTML title report — timeline, findings with evidence, and an auditable per-deed data table.

What it can analyze

Organised as tiers. The POC commits to 0–2, demos a slice of 3, and stubs 4.

Tier 0 · Extraction POC core

Per deed: doc no, SRO, dates, deed type; parties (father/spouse, PAN, GPA holder); property (survey/plot, extent, boundaries, ULPIN); financials (consideration, stamp duty, e-stamp no); and the flow-of-title recital.

Tier 1 · Single-deed checks POC core

Completeness · words-vs-figures consistency · "is this really a sale, or a GPA / Agreement-to-Sell?" (legally weak post-2011) · stamp-duty adequacy · party red flags (minor / NRI / POA / agri land).

Tier 2 · Chain checks POC core — the IP

Identity continuity · property continuity · extent arithmetic (the "sells more than they own" = missing deed) · recital linkage · temporal gaps · traces-to-root · and telling a missing registered deed apart from a legitimate non-registrable transition (inheritance/partition) so it doesn't cry wolf.

Tier 3 · Risk & fraud signals POC demos a subset

GPA-sale flag · under-valuation / under-stamping · suspicious price movement · boundary drift · encumbrance contradiction · (image-level) tamper signs.

Tier 4 · Registry & authenticity Phase-2 · advisory

e-Stamp verify (SHCIL) · PKI signature validation · QR decode · EC cross-check via aggregator. Reality: India has no official title API — registry retrieval is manual/CAPTCHA, so this tier is advisory, never presented as authoritative.

What the POC proves — and its limits

Proves: extraction quality, chain-validation logic, and explainable reporting on a handful of real deeds.

Does not: give a legal opinion on marketable title, verify against the government registry, or prove production scale. It flags for a human, never auto-clears title — failure in the safe direction.
