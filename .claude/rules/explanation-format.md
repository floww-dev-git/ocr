# Code Explanation Format

When the user asks to explain code — "explain this", "walk me through X", "how does Y work",
"help me understand Z" (a file, script, module, function, or any code) — load
`.claude/rules/references/explanation-format.md` and follow its structure (7-section first-pass
format; the two follow-up-only deep-dive variants). Applies to every agent and the main session.
